## Anti-AI Writing Rules

所有平台的文案都必须遵循以下规则，避免被平台识别为 AI 生成内容而限流。

### What NOT to Write (AI 痕迹特征)

```
"首先，韶山是一个具有深厚红色文化底蕴的旅游目的地。
 其次，这里拥有丰富的历史遗迹和优质的旅游服务设施。
 最后，建议游客提前规划行程，以获得最佳的旅游体验。
 总而言之，韶山是一个值得一游的红色旅游胜地。"
```

问题：句式整齐划一、连接词堆砌、没有具体细节、每句话都像百科全书。

### What to Write (真人写作风格)

```
说实话，去之前我对韶山没什么特别的期待——就觉得是个红色景点嘛。

但到了故居门口那一刻，真的被震到了。排队的人从门口一直绕到停车场，
老人小孩都有，好多人是全家一起来的。

我们请了个本地导游（强烈建议！），讲解的时候你能感觉到她是真的热爱
这段历史，不是在背台词。门票免费，但要提前预约，这点很多攻略没写。

（对了差点忘说，故居旁边有家米粉店，牛肉粉12块钱一碗，排队的都是
本地人，比景区大门那边的好吃太多了）
```

### Key Principles

1. **用真实细节替代空洞描述**：价格、地址、排队时长、具体菜名，这些是 AI 编不出来的
2. **句式长短交替**：一句话的段落和五六句的段落混着来
3. **允许跑题和碎碎念**：真人写作经常会插入题外话再拉回来
4. **主观感受 > 客观描述**："震到了"比"令人印象深刻"更真实
5. **括号吐槽**：用括号加入心理活动或补充说明，这是真人写作的典型特征

## WeChat Official Account Templates (公众号推文)

### Template 1: 攻略型推文
```
标题：[地点/主题]+攻略 | [核心价值点]

正文结构：
引言（100字以内）：
  简述主题背景 + 阅读价值预告

▍一、[分类1]
  具体内容 + 配图
  Tips/小贴士

▍二、[分类2]
  具体内容 + 配图
  Tips/小贴士

▍三、[分类3]
  具体内容 + 配图
  Tips/小贴士

总结（50字以内）：
  核心要点回顾

互动引导：
  "你最想去哪里？评论区告诉我们～"

---
[品牌信息 + 往期推荐 + 关注引导]
```

### Template 2: 深度解读型
```
标题：深度 | [话题/趋势]+[独到观点]

正文结构：
导读（150字以内）：
  行业背景 + 核心问题引出

▍现状：[行业/话题]正在发生什么变化？
  数据 + 案例

▍分析：为什么会出现这种变化？
  原因 1 + 论据
  原因 2 + 论据

▍影响：这对我们意味着什么？
  影响分析 + 应对建议

▍展望
  趋势预判 + 行动建议

互动引导：
  "你怎么看这个趋势？欢迎留言讨论。"
```

### Template 3: 故事型推文
```
标题：[人物/品牌] | [引人入胜的故事钩子]

正文结构：
开头（设置悬念或情感共鸣）：
  "那天下午，他做了一个改变一切的决定……"

故事展开：
  背景 → 冲突 → 转折 → 结果

核心启示：
  从故事中提炼 2-3 个关键洞察

与读者的连接：
  "也许你也正面临这样的选择……"

引导行动：
  "如果这个故事打动了你，转发给身边需要的朋友。"
```

### Anti-AI Example (公众号)

```
AI 痕迹写法：
  "韶山是一个美丽的红色旅游胜地，拥有丰富的旅游资源和优质的服务设施。
   首先，毛泽东故居是必游之地。其次，纪念馆值得深入参观。
   最后，当地的餐饮也独具特色。总之，韶山是一次难忘的旅行体验。"

去 AI 化写法：
  "不瞒你说，决定去韶山之前我犹豫了挺久——总觉得红色景点嘛，
   半天就逛完了。结果到了才发现，光故居和纪念馆就花了大半天，
   导游讲的那些细节课本上根本没有（比如主席小时候在池塘边读书
   的故事，我听得都入迷了）。

   最后说个实在的：故居免费但一定要提前 3 天预约，
   我们前面有个大哥没预约，大老远跑来进不去，别提多可惜了。"
```

## Sohu Templates (搜狐号文章)

### Template 1: 资讯解读
```
标题：[事件/话题]：[核心信息] + [价值点]
示例："2026年国内旅游市场回暖：这5个目的地预订量涨超200%"

正文结构（800-1500字）：

导语（100字以内）：
  交代事件核心信息（5W1H）

背景：
  相关行业/政策背景

详情：
  具体数据和信息展开
  配图：相关数据图表或场景图

分析：
  专家/业内观点
  趋势判断

影响：
  对用户/行业的实际影响
  实用建议

小结：
  核心信息回顾（2-3句话）
```

正文结构（1000-2000字）：

  详细内容 + 配图
  实用 Tips

  详细内容 + 配图

  详细内容 + 配图
  实用 Tips

  关键注意事项汇总

  Q1: ...
  A1: ...

## Hook Formulas (标题公式)

### 数字型
- "[数字] + [主题] + [效果]" — "5个三亚必打卡的免费景点，本地人都推荐！"
- "[时间] + [成果]" — "3天学会手冲咖啡，新手也能做出咖啡店水平"
- "人均[金额] + [体验]" — "人均200吃遍成都老街，这份清单请收好"

### 悬念型
- "[结果]，原来是因为[原因]" — "酒店价格突然跳水，原来是因为这个政策"
- "千万别[动作]，除非你知道[信息]" — "千万别在旺季订酒店，除非你知道这个省钱技巧"
- "[意外发现]" — "在三亚发现一家人均50的海鲜店，味道碾压大排档"

### 对比型
- "[A] vs [B]，到底选哪个？" — "三亚湾 vs 亚龙湾，第一次去到底住哪里？"
- "[之前] → [之后]" — "从月薪5000到副业月入2万，我做对了这3件事"

### 攻略型
- "[年份]+[主题]攻略" — "2026三亚自由行超全攻略，照着走就对了"
- "第一次[做某事]，看这一篇就够了" — "第一次去日本，看这一篇就够了"
- "[身份]亲测 + [结论]" — "旅行博主亲测：三亚这10家酒店性价比最高"

### 情感型
- "后悔没有早点知道[信息]" — "后悔没有早点知道的三亚省钱技巧"
- "[强烈情感词] + [内容]" — "惊艳！这个藏在大山里的古村落太美了"

### 实用型
- "建议收藏 | [主题]+[内容概述]" — "建议收藏 | 三亚旅游防坑指南，这些套路要知道"
- "一文搞懂[复杂话题]" — "一文搞懂签证办理全流程，小白也能自己搞定"
